*   **Title:** Customer.io: Contract Accounts Payable Manager

*   **Summary:** This is a 6-month contract role focused on Accounts Payable and Travel & Expense (T&E) management. Experience with NetSuite or a comparable ERP is a plus.
*   **Rating:** N/A (This is an accounting/finance role, not a software development position. While it uses modern finance tools, it doesn't have a "tech stack" in the traditional developer sense.)

*   **Title:** Glean: Application Security Engineer
*   **Link:** https://weworkremotely.com/remote-jobs/glean-application-security-engineer
*   **Stack Category:** Security Engineering (DevSecOps)
*   **Summary:** This Application Security Engineer will own the vulnerability management lifecycle across Glean's technology stack. Key responsibilities include hardening base OS images, securing open-source dependencies, integrating SAST, DAST, and dependency scanning into CI/CD pipelines, evaluating security solutions (e.g., Google’s Assured OSS), and defining secure-coding practices. Requires 8+ years in application security and vulnerability management, deep understanding of CVEs, OWASP Top 10, hands-on experience with various security tools (Snyk, GitHub Dependabot, Trivy, Clair, Burp Suite, OWASP ZAP), and cloud-native security expertise (AWS, GCP, containers, Kubernetes, microservices).
*   **Rating:** ★★★★★
    *   **Modernity Take:** This is a cutting-edge role in a critical area, leveraging modern DevSecOps practices. The focus on cloud-native security across AWS/GCP, Kubernetes, microservices, and integrating advanced scanning tools directly into CI/CD pipelines demonstrates a highly modern and proactive security posture.

*   **Title:** Hex Technologies: Cloud Security Engineer
*   **Link:** https://weworkremotely.com/remote-jobs/hex-technologies-cloud-security-engineer
*   **Stack Category:** Cloud Security Engineering (DevSecOps & Platform)
*   **Summary:** This Cloud Security Engineer will secure Hex's cloud infrastructure and RCE-as-a-Service platform, specifically within AWS environments and Kubernetes clusters. Responsibilities include designing security solutions, building infrastructure-as-code with Terraform, conducting security assessments, embedding best practices into CI/CD, and monitoring incidents. The core Hex stack involves TypeScript, React, Apollo GraphQL, Redux on the frontend; TypeScript, Express/Apollo GraphQL, Postgres, Redis, Kubernetes on the backend; and Terraform, Helm, AWS for infrastructure. Requires 5+ years in cloud security engineering, extensive AWS/Kubernetes security expertise, Terraform mastery, and familiarity with AWS security services (IAM, GuardDuty, Security Hub, CloudTrail, WAF), CNAPP solutions (Wiz), and SIEM solutions (Panther).
*   **Rating:** ★★★★★
    *   **Modernity Take:** This is an outstandingly modern role. It combines deep cloud security (AWS, Kubernetes hardening, RCE-as-a-Service considerations) with Infrastructure-as-Code (Terraform, Helm), and cutting-edge security tooling (Wiz, Panther). The underlying application stack (TypeScript, React, GraphQL) further solidifies its position as fully modern.
